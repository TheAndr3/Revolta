# Imagens-âncora

Imagens aprovadas no **teste de estilo (#21)** que fixam o estilo de cada série. Elas são anexadas como referência em todo prompt da série correspondente (ver [estilo-ilustracao.md](../estilo-ilustracao.md#imagens-âncora) e [estilo-gameplay.md](../estilo-gameplay.md#prompt-base-pixellab)).

Esta pasta começa vazia. Ao aprovar uma âncora no teste de estilo:

1. Salve a imagem aqui com um nome que diga a série, ex.: `ancora-provas.png`, `ancora-retratos.png`, `ancora-gameplay-protagonista.png`.
2. Registre o prompt dela em `art/prompts/` como qualquer outro asset.
3. Atualize a tabela de âncoras no guia da camada.
